# 행복시 청년정보 ON · SB 화면 안내

`yjgeum/index.html`을 정적 웹 서버로 열어 확인합니다. 원본 디자인과 서비스 시연 동작을 유지하면서 공통 SB 도구를 연결했습니다.

- 상단 화면 선택 또는 화면검색에서 화면을 선택합니다. 화면검색은 ID·화면명·분류로 검색합니다.
- Description은 기본 닫힘이며, 열기 버튼으로 영역 설명과 알럿/컨펌 탭을 확인합니다.
- 설명 작성·수정·삭제와 번호 핀 저장은 공통 서버의 GitHub 공동작업자 인증이 필요합니다. 서버·인증 설정은 변경하지 않았습니다.
- 사이트의 데모 로그인·신청·투표·예약은 개인 브라우저의 시연 데이터입니다. SB 설명의 공동 저장과 별개입니다.
- 신청 등 팝업을 연 뒤 Description 버튼을 누르면 부모화면ID-pNN으로 분리해서 설명할 수 있습니다. 닫기 버튼으로 부모 화면 설명으로 돌아갑니다.
- 검색 필터는 URL의 view 값에 보관하여 화면 ID와 설명이 필터마다 달라지지 않습니다.
- 직접 추가된 기능 설명은 없습니다. 아래 화면에서 기획 내용을 작성해 나갑니다.
