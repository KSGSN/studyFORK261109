# 기획팀 스터디

제공된 `AGENTS.md`, `common/`, `mjha/`, `index.html`을 기준으로 한 초기 구성입니다.

- `index.html`: 프로젝트 목록
- `common/`: 공통 기획·Description 도구
- `mjha/`: 빈 개인 실습 공간
- 저장소: https://github.com/with-demo/study
- 사용 안내: [common/README.md](common/README.md)

설명 편집은 로그인·저장 서버 없이 동작합니다. 프로젝트별 `descriptions.json`을 자동으로 읽습니다. 편집 내용은 현재 브라우저에 임시 보관하며, 상단의 **JSON 내보내기 / JSON 불러오기**로 파일을 저장·이동할 수 있습니다. HTML·JS나 GitHub 파일을 자동으로 수정하지 않습니다. 자세한 사용법은 [공통 도구 안내](common/README.md)를 확인하세요.
