# 핵심 기능 Description 1차 초안

## HOME-01 · 담당·멘션 알림

- 알림 버튼을 누르면 담당자로 지정되었거나 @mjha 멘션이 포함된 업무 알림을 표시한다.
- 읽지 않은 알림 개수를 표시하고 개별 선택 또는 모두 읽음으로 읽음 처리한다.
- 개별 알림을 선택하면 연결된 업무 상세를 연다.

정책: 최근 30일 알림만 조회한다. 현재 초안은 예시 알림과 화면 내 업무 등록으로 생성하며 실제 푸시는 발송하지 않는다.

검토사항: 시트 요구: 30일 이후 자동삭제. 현재 목업은 최근 30일 조회 필터이며 서버 자동삭제는 미구현.

## CAL-01 · 업무 캘린더·기간 전환

- 프로젝트 보드에서 캘린더 표시를 체크한 업무를 시작일~종료일에 노출한다.
- 월·주·일 보기를 전환하고 이전·다음·오늘로 조회 기간을 변경한다.
- 프로젝트를 선택하면 해당 프로젝트 일정만 표시한다.
- 일정을 누르면 업무 상세를 열고, 날짜를 누르면 해당 날짜의 일간 보기로 이동한다.

정책: 월·주·일 화면에 공통 적용한다. 체크 해제한 업무는 업무 보드에는 남고 캘린더에서만 제외한다. 일정이 없으면 빈 상태를 표시한다.

검토사항: 현재 초안은 체크된 팀 업무를 함께 표시한다. 본인 담당 업무만 표시할지, 팀 업무 포함 여부는 추가 협의 필요.

## PRJ-01 · 프로젝트 생성

- 프로젝트명, 설명, 계획 단위(월·주·일), 시작일과 종료일을 입력한다.
- 프로젝트명·시작일·종료일은 필수이며 종료일이 시작일보다 빠르면 등록하지 않는다.
- 생성 후 해당 프로젝트 보드로 이동한다.

정책: 추가한 프로젝트는 현재 페이지에서만 유지된다. 실제 공유·서버 저장·새로고침 후 복원은 연결하지 않는다.

검토사항: 프로젝트 생성 권한과 계획 단위별 기간 자동 계산은 미확정. 현재는 직접 입력한 기간을 사용.

## PRJ-02 · 업무 등록·수정

- 업무명, 프로젝트, 시작일·종료일, 시간, 담당자, 상태, 중요도, 업무 내용, 태그를 입력한다.
- 업무명·시작일·종료일·시간은 필수이며 공백 업무명과 종료일 역전은 등록하지 않는다.
- 보드 상단 업무 추가 또는 각 단계의 업무 추가로 작성한다. 단계에서 추가하면 해당 상태를 기본 선택한다.
- 업무 제목을 누르면 상세·수정 창을 연다.

정책: 필수 입력 또는 기간 오류가 있으면 창을 유지해 수정한다. 현재는 페이지 메모리에만 반영하며 태그는 실제 사용자 검색이 아닌 텍스트 입력이다.

검토사항: 새 업무 ID는 화면 내부 식별용. 파일 첨부·댓글·실시간 공동편집은 초안 범위에 포함하지 않음.

## PRJ-02 · 업무 시작·완료 상태

- 할 일 / 진행 중 / 완료 중 하나를 선택한다.
- 상태를 변경하면 해당 업무를 선택한 보드 열로 이동한다.
- 완료 건수와 프로젝트 진행률을 즉시 갱신한다.
- 대시보드의 완료 체크를 해제하면 할 일로 되돌린다.

정책: 진행률은 프로젝트의 완료 업무 수 ÷ 전체 업무 수로 표시한다. 업무가 없으면 0%다. 변경은 새로고침 전까지만 유지된다.

검토사항: 현재 목업에는 승인·상태변경 권한·시작/완료 시각 이력 관리가 없다. 실제 서비스 정책은 협의 필요.

## PRJ-02 · 캘린더 표시 여부

- 체크하면 업무의 작업 기간을 내 업무 캘린더에 표시한다.
- 체크 해제하면 월·주·일 캘린더에서 해당 일정만 숨긴다.
- 업무 본문, 보드 상태, 담당자와 완료 집계는 유지한다.

정책: 업무별로 독립 적용한다. 신규 업무는 표시 상태로 시작하며 수정 창에서도 같은 값을 변경할 수 있다.

## ATT-01 · 출근·퇴근 기록

- 출근을 누르면 한국 시간 기준 현재 시각을 출근 시각으로 표시한다.
- 출근 후에는 중복 출근을 막고 퇴근 버튼을 활성화한다.
- 퇴근을 누르면 퇴근 시각을 표시하고 당일 추가 기록을 막는다.
- 대시보드의 근무 상태와 근무 내역에 같은 기록을 표시한다.

정책: 출근 전 퇴근은 불가하다. 현재는 화면 검토용 기록이며 실제 근태 시스템에 저장되지 않고 새로고침하면 초기화된다.

검토사항: 지각·조퇴·자정 경과·수정 요청·일자별 영구 저장 정책은 미확정.

## ATT-01 · 외근·연차 등록

- 연차 또는 외근을 선택하고 시작일·종료일·사유를 입력한다.
- 사유는 공백만 입력할 수 없고 종료일은 시작일보다 빠를 수 없다.
- 등록한 일정을 근무 내역에 표시한다.
- 연차는 예시 잔여 일수를 초과하면 등록을 막는다.

정책: 검토용 기준은 연차 15일, 양끝 날짜를 포함한 달력 일수로 계산한다. 외근은 연차 잔여에서 제외한다. 서버 저장과 실제 승인 처리는 하지 않는다.

검토사항: 15일 부여, 주말·휴일 포함 계산은 목업 가정이다. 승인 절차·연차 차감 기준·반차·외근 시간 단위는 확정 필요.

## MEM-01 · 최고관리자 계정 발급

- 별도 회원가입 없이 최고관리자가 계정을 발급하는 흐름이다.
- 이름/아이디, 팀소속, 직위, 이메일을 입력한다.
- 아이디는 공백을 제외하고 대소문자를 구분하지 않아 중복을 검사한다.
- 등록 후 회원 목록에 활성·일반회원으로 추가한다.

정책: 현재는 최고관리자 검토 역할의 목업으로 실제 권한 검증·계정 생성·메일 발송은 없다. 최고관리자 본인의 비활성 버튼은 비활성이다.

검토사항: 실서비스에서는 서버 권한 검증 필수. 이름과 아이디 분리, 최초 비밀번호 전달·재설정 정책은 추가 정의 필요.

## MY-01 · 내정보 변경

- 이름, 팀소속, 직위, 내선번호, 휴대번호, 이메일을 수정한다.
- 이름·팀소속·직위·휴대번호·이메일은 필수이며 이메일 형식 검사를 적용한다.
- 비밀번호 입력 시 확인값과 다르면 저장하지 않는다.
- 저장 후 화면의 프로필 표시를 갱신한다.

정책: 계정 ID는 유지되는 목업이며 변경 정보는 현재 화면에만 적용한다. 새 비밀번호는 일치 여부만 확인하고 저장·전송하지 않는다.

검토사항: 비밀번호 강도·현재 비밀번호 확인·휴대번호 형식·실제 정보 저장 정책은 미확정. 실제 개인정보 입력 금지.

## LOG-01 · 발급 계정 로그인

- 관리자가 발급한 ID와 비밀번호를 입력한다.
- 두 항목은 필수이며 미입력 시 제출하지 않는다.
- 목업으로 로그인하면 대시보드로 이동하고 실제 인증이 연결되지 않았음을 안내한다.
- 회원가입 링크는 제공하지 않는다.

정책: 현재는 입력·이동 흐름만 검토한다. 비밀번호를 저장하거나 인증 서버로 전송하지 않는다. 실제 로그인 검증으로 간주하지 않는다.

검토사항: 실서비스의 오류 문구·잠금·비밀번호 재설정·세션 만료 정책은 추가 정의 필요.
