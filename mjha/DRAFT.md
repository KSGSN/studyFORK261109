# WORKSPACE · 업무관리시스템 1차 초안

기준: 기획팀_스터디용 사이트맵의 메뉴별 기능 탭 (gid=1470679035).
작성일: 2026-11-08 (한국 시간). 화면·기능 변경은 mjha/에 한정합니다.

## 시트에서 반영한 범위
- 내 업무: 월·주·일 캘린더. 프로젝트 게시판에서 캘린더 표시를 체크한 일정 노출.
- 프로젝트: 프로젝트 목록·추가(월/주/일 계획 단위), 업무 작성·수정, 담당자·기간, 시작·완료 상태.
- 근태: 출퇴근 기록, 외근·연차 등록 흐름.
- 알림: 담당자·멘션 알림, 최근 30일 조회, 읽음 처리.
- 내정보: 이름·비밀번호 입력·팀소속·직위·내선·휴대번호·이메일.
- 회원관리: 최고관리자의 계정 발급 흐름. 별도 회원가입 없음.
- 로그인: ID/PW 입력 흐름. 실제 인증으로 처리하지 않음.

## 검토를 위해 가정한 사항
- 사이트명 WORKSPACE, 대시보드, 보드의 할 일/진행 중/완료 상태, 우선순위는 초안 제안.
- 본문 데이터는 가상의 검토용 자료. 전화·이메일은 예시 값.
- 연차는 15일 예시. 승인 절차·차감 기준·주말 처리·외근 시간 단위는 미확정.
- 회원관리 화면은 최고관리자 검토 역할로 표시. 실제 권한 검증 없음.
- 알림은 현재 화면에서 등록한 업무의 담당자 또는 @mjha 태그를 예시로 사용.

## 저장과 검증 한계
실제 로그인, 계정 생성, 근태 기록, 서버 저장, 메일 전송은 연결하지 않습니다.
입력·업무 상태 변경은 현재 페이지의 메모리에만 유지되고 새로고침하면 초기화됩니다.
비밀번호는 저장하지 않습니다. 실제 개인정보나 비밀번호를 입력하지 마세요.
상단 공통 Description 도구와 서버 설정은 변경하지 않습니다.
